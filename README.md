# Kajsa Inreder – färdig webbplats

Ladda upp innehållet i denna mapp till roten av ditt GitHub-repository. index.html ska ligga direkt där, tillsammans med styles.css, app.js, alla undersidor och assets-mappen.

GitHub Pages: välj Settings → Pages → Deploy from a branch → main och / (root). Alla interna länkar och bildsökvägar är relativa. Ingen installation eller byggning behövs.

Kontaktformuläret öppnar ett mejlutkast som besökaren själv skickar. Det finns ingen serverbaserad formulärleverans eller databas.

Byt den fullständiga domänen i sidornas canonical/og:url/JSON-LD samt sitemap.xml och robots.txt vid flytt till den riktiga domänen.

Bilder och sakuppgifter kommer från Kajsa Inreders befintliga webbplats. Kundomdömen är källhänvisade. Bildrättigheter kvarstår hos respektive rättighetsinnehavare. Inga betyg eller resultat har uppfunnits.
